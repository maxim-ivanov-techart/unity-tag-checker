# Tag Checker

Unity Editor tool for finding all GameObjects with a specific tag in your scene.

## Features

- Search active and inactive objects (toggleable)
- Shows full hierarchy path
- Click to select and frame it in Scene view
- Select All button for bulk operations
- Enter hotkey to search without clicking

## How to use

1. Drop `TagChecker.cs` into any `Editor` folder in your project
2. Open `Tools > Tag Checker` in Unity
3. Pick a tag from the dropdown
4. Hit Search (or press Enter)
5. Click any result to jump to it
